10// =============================================================================
11// VisualizerManager
12//
13// Responsibilities:
14// 1. Scan <exe dir>/Visualizers/ for *.dll files.
15// 2. Load each DLL with juce::DynamicLibrary, resolve createVisualizer().
16// 3. Manage plugin lifecycle (initialise / render / shutdown).
17// 4. Implement IAudioSource so plugins can query FFT / waveform data.
18// 5. (Phase D) Manage which plugin is currently displayed.
19// 6. (Phase D) Auto-switch plugins on a timer (Sequential / Random).
20// 7. (Phase E) Rescan Visualizers/ folder at runtime.
21//
22// Thread safety:
23// All public methods (except render) must be called from the message thread.
24// render() is also message-thread only (called from a repaint/timer).
25// The IAudioSource methods are likewise called from the plugin's render(),
26// which runs on the message thread. Audio data is copied with a SpinLock.
27// =============================================================================
