Rebuild Core's audio graph for serial effect-chain routing.

Instruments are processed in parallel (MultiSourceBridgeProcessor), each with its own per-channel FX chain (perChannelFxMap), then the mixed output is fed through each master effect bridge in order. inputFxChain: serial FX applied to physical audio input before it merges into the master chain. Physical input is always active — LINE works even with no instrument bridges loaded. Graph: [Instr(parallel+per-chan FX)] → [MasterFX1] → ... → [Gain/Meter] → [Out] [PhysIn] → [InputGain] → [InputFX...] ↗
