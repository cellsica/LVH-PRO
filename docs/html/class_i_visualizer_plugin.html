Detailed Description

Abstract interface that every LVH visualizer DLL must implement.

A DLL placed in the <LVH.exe dir>/Visualizers/ folder is loaded at startup by VisualizerManager. The DLL must export a single C-linkage factory function:

extern "C" __declspec(dllexport)
IVisualizerPlugin* createVisualizer();

Lifecycle:

  1. Host calls createVisualizer() to obtain an instance.
  2. Host calls initialise() once with an IAudioSource pointer.
  3. Host calls render() on every repaint cycle (message thread).
  4. Host calls shutdown() before unloading the DLL.
  5. Host calls delete on the instance.

All methods are called from the message thread unless otherwise noted. The plugin does not own the IAudioSource passed to initialise().
