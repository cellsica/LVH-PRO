# 【しずく（Claude Code）への依頼】第6回：機能集約とモニタリングシステムの実装（決定版）

## 1. 依頼内容
LVH の UI を整理し、プロ向けホストとしての「情報密度」と「使い勝手」を両立させるための大規模なアップデートをお願いします。
ツールバーのごちゃつきを解消し、タイトルバーへの情報集約、および出力レベル・MIDI信号の可視化を実装してください。

## 2. 実装のゴール

### A. ツールバーの整理とタイトルバー連動
- **タイトルバー**:
    - プラグインがロードされている場合、ウィンドウタイトルを `LIGHT-VST-HOST [プラグイン名]` に変更してください。
    - 未ロード時は `LIGHT-VST-HOST` に戻してください。
- **ツールバーの整理**:
    - **UNLOADボタン**: プラグイン未ロード時は無効（灰色）にしてください。
    - **メッセージエリアの削除**: タイトルバーで状況がわかるようになるため、現在の `statusLabel`（ツールバー右端のテキストエリア）は削除し、空いたスペースをモニタリング機能に充ててください。

### B. MIDI 入力選択の統合
- **仕様変更**:
    - 現在の「MIDI 選択ボタン」を削除し、**「LOAD」アイコン（またはプラグイン選択メニューの並び）**周辺のロジックに統合してください。
    - 具体的には、プラグイン選択メニュー、またはロゴメニュー等の中に「MIDI Input」というサブメニューを作成することを検討してください。
- **メニュー内容**:
    - 利用可能な MIDI 機器を一覧表示。
    - **選択中の機器には `✔` マーク** を表示。
    - 機器が存在しない場合は `No MIDI Device` と表示。

### C. モニタリング・コントロール機能 (ツールバー右側に配置)
以下の 3 つをこの順序で、ツールバーの右端方向に配置してください。

1. **メインボリューム (Volume)**:
    - シンプルでモダンなスライダー。
    - `audioEngine.getPlayer().setGain()` を操作。
2. **レベルメーター (Level Meter)**:
    - L/R チャンネルごとに 2 行のインジケーターを表示。
    - 横長のデザインで、音量に合わせて伸び縮みするもの。
    - `AudioEngine` で最終バッファからピーク値を取得してください。
3. **MIDI モニター (MIDI Monitor)**:
    - 最後に受信した MIDI 信号をテキストで表示。
    - 例: `Note: 60 (C4) Vel: 100 Ch: 1`
    - 受信した瞬間に更新し、一定時間（または次のノートまで）保持。

## 3. 実装のヒント
- タイトルバーの変更は `JUCEApplication::getInstance()->getMainWindow()->setName()` または `DocumentWindow::setName()` で行います。
- レベルメーターは `juce::Timer` を使用して、20ms〜33ms 周期で描画更新するのがスムーズです。
- 各コンポーネントは将来「設定」で表示 ON/OFF できるよう、独立したクラスとして定義することを推奨します。
