# 指示書作成ルール
- write_to_fileツールは不具合発生中につき使用しないこと
  - Antigravityの改善待ち
- powershellによる出力は使用しないこと
  - 文字コードの問題があるため
- 無理に自動出力せず、ドキュメントの安全性が十分に担保できない場合は、チャット欄にmarkdown形式テキストを貼り付ける
  - テキストはコピペしやすいようにmarkdownの書式そのままで貼り付けてほしい。
- しずくへの指示書は以下の形式で作成する
  - to_shizuku_###.md
  - ###は基本的のロードマップのMission番号を用いる
  - Mission内がフェーズ分割されていた場合 ###_A のようにフェーズ番号が付与される
