## 🎯 今回の目標 (Mission 035-A 〜 E)

### 035-A: 安定性向上 (Bridge クラッシュ現象の究明) 【最優先】
- **現象**: 特定のプラグインをロードしてしばらくすると Bridge プロセスが落ちることがある。
- **タスク**:
    - `IPCManager` や `BridgeInstance` 周辺のログを強化し、クラッシュ時のスタックトレースやエラーメッセージを捕捉できるようにする。
    - 可能であれば原因を特定し、修正する（スレッド安全性の確認など）。

### 035-B: Settings リフレッシュボタン追加
- **タスク**:
    - `Settings > Plugin Path` 画面に「Refresh」ボタンを追加して。
    - 現在 Instrument 選択メニューにある「Rescan/Refresh」と同じロジックをここからも叩けるようにしてほしいな。

### 035-C: Global Layer (Stage Set 拡張)
- **タスク**:
    - Stage Set において「Global Layer」オプションを実装。
    - これが ON の時、Stage Set 内の最初のプロジェクトの設定（MIDI CC、ウィンドウ配置、サイズ）を、以降のプロジェクト読込後にも動的に上書き適用する仕組み。
    - ※プロジェクトファイル自体は書き換えず、メモリ上でのみ適用すること。

### 035-D: メトロノーム機能
- **タスク**:
    - `MetronomeManager` を新設。BPM 管理とクリック音生成（Hi/Lo）ロジックの実装。
    - メインツールバーまたは独立パネルへの UI 表示と Start/Stop 機能。

### 035-E: 究極の VU メーター (茜流物理挙動 ＆ 質感)
- **タスク**:
    - 独立した Floating Window としての VU メーターを実装。
    - **物理エミュレーション**: 300ms 積分時間、0dB 超え時のオーバーシュート（揺れと戻り）、ダンピング。
    - **ビジュアル**: 透過文字盤、ガラスの反射、電球色/ネオンオレンジ等のカラー切替。
    - **特殊仕様**: 「クリック透過（Click-Through）」モードの実装。
    - ※詳細は `memo.txt` にある茜ちゃんの熱い提案を隅々まで読んでね！

まずは **035-A (クラッシュ調査)** から着手してほしいんだ。
安定性が確認できたら、B -> C -> D -> E と順番に進めていこう。
