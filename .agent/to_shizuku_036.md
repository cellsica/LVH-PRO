## 🎯 目的
設定画面（SettingsWindow）のユーザー体験向上。
特に「プラグインが見つからない」「パスを追加したのに反映されない」といった初期のストレスを解消するための機能追加と、全体的な UI のブラッシュアップを行う。

## ✅ 作業内容

### 1. Plugin Paths ページに「Rescan」ボタンを追加
**ファイル**: `Source/SettingsWindow.cpp` (`PluginPathsPage` クラス)

- 現在はパスを追加/削除した時に自動でスキャンが走るけど、ユーザーが手動で「今すぐ再スキャンしたい」時のために、明確な「Rescan Plugins」ボタンを追加してほしいんだ。
- `addBtn`, `rmBtn` の横か、リストの右下あたりに配置してね。
- クリック時は `if (onPathsChanged) onPathsChanged();` を呼び出せば、`UIManager` 経由でスキャンが走るはずだよ。

### 2. General ページのレイアウト・マージン調整
**ファイル**: `Source/SettingsWindow.cpp` (`GeneralSettingsPage` クラス)

- 現在のレイアウトを少し見直して、ラベルとコントロールの余白（マージン）を JUCE の標準的なガイドラインに沿って整えてほしいな。
- ちょっと窮屈に見える部分があるから、`resized()` 内の数値を見直して、ゆったりしたプロっぽい見た目にしてね。

### 3. ハードコードされた文字列の i18n 化
**ファイル**: `Source/SettingsWindow.cpp`, `Source/SettingsWindow.h`

- `SettingsWindow` 内でまだ `LvhStr` になっていないハードコードされた文字列（特に FileChooser のタイトルや MessageBox のテキストなど）を見つけて、多言語対応させてほしいんだ。
- 言語定義は `LanguageManager.h` に適宜追加してね。

### 4. 終了処理の安定化（フリーズ & プロセス残存の修正）
**最優先・重要事項**:
なべさんから「X ボタンで終了するときに Core が固まる」「画面は消えてもタスクマネージャーにプロセスが残る」という報告があったよ。

- `MainWindow::closeButtonPressed` および `shutdown()` 周りの処理を確認してほしいな。
- 特に `BridgeManager::shutdownAll()` で、全 Bridge プロセスの終了を待機する際のリミットや、IPC パイプのクローズ、スレッドの停止（`MidiSenderThread` など）が安全に行われているかチェックしてね。
- 必要なら、タイムアウト付きの強制終了ロジックを入れるなど、確実に Core が終了するように強化をお願いっ！
