# 【しずく（Claude Code）への依頼】第7回：設定画面の基盤とモニター領域の拡張

## 1. 依頼内容
LVH をさらに高機能かつカスタマイズ可能にするため、「二ペイン形式の設定画面プロトタイプ」の実装と、プラグインと鍵盤の間に「インテリジェント・モニター領域」を追加してください。

## 2. 実装のゴール

### A. 設定画面 (Settings Window) の基盤実装
- **形式**: 左側に縦のメニュー（ナビゲーション）、右側にコンテンツを表示するスタイル。
- **構成**:
    - **Global カテゴリ**:
        - **General**: ツールバーの項目表示設定（レベルメーター ON/OFF, MIDIモニター ON/OFF）を追加。※ボリュームは固定表示。
        - **Audio/MIDI**: JUCE 既存の `AudioDeviceSelectorComponent` を配置。
        - **Plugin Paths**: パス管理（UIのみでOK）。
    - **Plugin カテゴリ** (現プラグイン用):
        - **MIDI Settings**: トランスポーズ、チャンネルフィルタ設定。
        - **Info**: レイテンシー等の表示。
- **表示方法**: ロゴの右クリックメニュー「Settings...」から、この独立したウィンドウ（またはダイアログ）を呼び出せるようにしてください。

### B. モニター領域 (Info Monitor Panel) の追加
- **配置**: プラグイン表示エリア（Viewport）と仮想鍵盤（Keyboard）の間に新しい領域を追加してください。
- **挙動**: 仮想鍵盤と同様に、表示/非表示（トグル）およびスプリッタでの高さ調整を可能にしてください。
- **表示内容（暫定）**:
    - **MIDI Log**: メッセージ履歴のリスト表示。
    - **Status Indicators**: 大きな「受信チャンネル」表示、トランスポーズ状態、サスティンペダル（CC64）の状態。
    - **DSP Load**: CPU負荷を表示するバー（`AudioEngine` からサンプルごとの負荷を取得）。

### C. ツールバーの連動設定
- **General 設定との連動**: 設定画面でレベルメーター等を OFF にした場合、ツールバーの該当コンポーネントが非表示になり、レイアウトが再調整されるようにしてください。

## 3. 実装のヒント
- `MainComponent` の `StretchableLayoutManager` に、モニター領域用のスロット（ID: 3等）を追加してください。
- 設定の保存には `juce::ApplicationProperties` または `juce::ValueTree` を使用して、再起動後も設定が維持されるようにしてください。
