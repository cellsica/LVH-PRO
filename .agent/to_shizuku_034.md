## 🎯 今回の目標

1.  **各チャンネルへの MIDI 割り当て**: ミキサーの Vol / Pan / Solo / Mute を MIDI CC で制御できるようにする。
2.  **MIDI Learn 機能（チャレンジ！）**: ユーザーが直感的にマッピングできるように、右クリックメニュー等から「MIDI Learn」ができる仕組みを作ってほしいんだ。

---

## 🛠 実装詳細

### 1. MIDI 受信ロジックの拡張 (`UIManager`)
- Mission 033 で作った `handleMidiRemote()` をさらに拡張してね。
- 受信した MIDI CC が「どのチャンネルの、どのパラメータ」に対応するかを判定して、各 `BridgeInstance` のアトミック変数（`mixerGain` 等）に値を流し込む処理を作ってほしいんだ。

### 2. MIDI マッピングデータの管理
- 各チャンネル（ストリップ）ごとに、どの CC 番号が Vol / Pan 等に割り当てられているかを保持するマップを用意してね。
- このマッピング設定も `ApplicationProperties` に保存・復元されるようにする必要があるよ。

### 3. MIDI Learn 機能の実装
- **UI 操作**: 
    - `MixerStrip` の各コントロール（フェーダー、パンスライダー、S/Mボタン）を右クリックして、「MIDI Learn」を選択できるようにしてね。
- **キャプチャ**:
    - Learn モード中は、最初に入ってきた MIDI CC をそのパラメータに紐付けるようにしてほしいんだ。
    - 紐付けが完了したら Learn モードを自動で抜けるようにしてね。
- **視覚的フィードバック**:
    - Learn モード中のコントロールは、色を変えるなどして「待機中」なのがわかるようにしてね。

### 4. 言語リソースの追加
- 「MIDI Learn」などの新しい文言を `LanguageManager.h` に追加してね。
