# LVH-PRO (Pro Version) プロジェクト開発指示書 (instructions.md)

このドキュメントは、プロジェクト「LVH-PRO」におけるAIアシスタントの開発指針と技術仕様をまとめたものです。

## 1. 基本行動指針
- **概念**: Pro版は、マルチプロセス・サンドボックス構造を採用した次世代VSTホストです。
- **言語**: 全ての対話、ドキュメント、コードコメントは**日本語**で行います。
- **品質**: 既存の機能を壊さない（デグレードさせない）ことを最優先に考慮し、修正後は影響範囲を確認します。
- **タスクルーティング**: ユーザーからのコードに関する指示には、まず `/route_task` ワークフローに従って、自身（かえで）で対応するか Claude Code に任せるかを判定します。
- **ナレッジベース**: `.agent` フォルダ内のすべてのドキュメント、ワークフロー、および指示書は、プロジェクトのマスターナレッジとして扱います。
- **ペルソナ管理**: 性格設定ファイルは `.agent\workflows\persona.md` に配置します。
- **アーキテクチャ優先**: Pro版では「独立性」と「堅牢性」を重視します。各コンポーネントの分離を徹底してください。

## 2. プロジェクト概要
- 仕様は、`specifications.md` および `PRO_VERSION_PLAN.md` を参照してください。
- 開発チーム構成は、[team.md](./workflows/team.md) を参照してください。

## 3. 技術仕様 (Pro版)
- **マルチプロセス**: AudioEngine (Commander) と PluginBridge (Child) の分離。
- **IPC**: 共有メモリとロックフリー・バッファによる通信。
- **UI**: 全ウィンドウの OS レベルでの独立・フローティング化。

## 4. コーディング規約
- JUCE フレームワークを使用。
- ヘッダー設計における依存関係の最小化（Forward Declaration の活用）。

## 5. ロードマップ
現在の開発状況は仕様書および `roadmap.md` を参照してください。

## 6. 他のAIとの連携
- Geminiアプリ(Gem)との連携は、docs/fromGems配下に保存する。

## 7. コード管理(Git)
- **ブランチ構成**: `main` (リリース), `develop` (開発ベース)。
- **ワークフロー**: `feature/xxx` ブランチでの開発。

## 8. バージョン管理
- バージョン形式: `[X.Y.Z]`
- Pro版初期バージョン: 0.1.0

## 9. タスク継続ルール
- 開発を中断する際は、必ず `.agent/next_task.md` に次回のタスクを書き出すこと。
- 起動時に `/on_startup` を通じて `next_task.md` を読み込み、[ ]（未確認）のタスクを [X]（確認済）に更新すること。
## 10. AI間連携規程 (かえで・しずく)
- **連携方式**: かえで（設計・相談担当）としずく（実装担当）の間で指示・報告を行う際は、必ず `.agent/to_(相手名)_(連番).md` という形式のファイルを作成して行います。
- **仲介と承認**: ユーザー（なべ）はこの指示書・報告書の内容を確認・承認することで開発を進行させます。
- **記述言語**: これらのドキュメントはすべて**日本語**で記述します。
- **履歴管理**: 連携用ドキュメントは削除せず、連番で履歴を保持します。

## 11. 公開・リリース時の規定
- **`.agent/` フォルダの保護**: 本プロジェクトを外部公開（GitHub へのパブリッシュ等）する際は、プライバシー保護と履歴の整理のため、`.agent/` フォルダ全体をリポジトリから除外、あるいは公開用ブランチから削除してください。
