# LVH-PRO Processor Plugin Specification: Looper & Recorder
**Version**: 1.0.0  
**Category**: Audio Processor Plugin (DLL)  
**Designer**: Akane (Music Application Designer)

## 1. 開発コンセプト
本プラグインは、LVH-PRO の `IProcessorPlugin` インターフェースを利用し、メインプロセス（Core）から独立した DLL として動作する。楽器（特にベースやギター）のリアルタイム演奏において、直感的な「一人アンサンブル」を実現するための多層録音・再生機能を提供する。

## 2. 機能仕様 (Core Functions)

### 2.1 マルチレイヤー・ルーピング
* **Base Layer Record**: 最初の録音でループ全体の長さ（小節数/時間）を決定する。
* **Infinite Overdub**: 既存のループ音を再生しながら、新しい演奏を重ねて録音する。レイヤーはスタックされ、個別に管理される。
* **Replace Mode**: 既存の音を消しながら新しい音で上書きするモード。
* **Undo / Redo**: 最後に重ねたレイヤーのみを取り消し、または再実行する。

### 2.2 オーディオ処理
* **Zero-Latency Monitoring**: 入力信号を遅延なく出力へスルーし、ループ音とミックスする。
* **Layer Mixer**: 各レイヤーの音量バランスを個別に調整可能にする（内部バッファの分離保持）。
* **Feedback Control**: 重ね録音時に古い音を徐々に減衰させる（ダビングによる音割れ防止）。

### 2.3 外部連携・保存
* **Instant Export**: 構築したループを即座に `.wav` 形式で書き出し、DAW 等へ受け渡し可能にする。
* **Project Sync**: LVH 本体のテンポ（BPM）および拍子情報を受け取り、録音開始・終了を小節の頭に自動補正（クオンタイズ）する。

## 3. 操作仕様 (Control Interface)

演奏中の操作を前提とし、全ての主要アクションは MIDI CC による外部制御をサポートする。

| アクション | トリガー | 挙動説明 |
| :--- | :--- | :--- |
| **Rec / Play / Overdub** | MIDI CC (Foot Sw) | 停止中：録音開始 / 再生中：重ね録音開始・停止 |
| **Stop** | MIDI CC (Foot Sw) | 再生・録音の即時停止 |
| **Undo** | MIDI CC (Hold) | 直前のレイヤーを破棄（ライブ中のミスリテイク用） |
| **Clear All** | UI Button | 全てのバッファをクリア |

## 4. 実装ガイドライン (for Developers)

1.  **分離プロセスの維持**:
    * 本プラグインは DLL としてロードされ、LVH 本体とは独立したメモリ空間でオーディオバッファ（`AudioBuffer<float>`）を管理すること。
2.  **マルチスレッド安全**:
    * オーディオレンダリングスレッド（`processBlock`）と、WAV書き出しスレッドの競合を完全に回避する。
3.  **バッファの動的確保**:
    * ループ長に応じてメモリを動的に確保するが、演奏中のプチノイズ（オーディオドロップアウト）を防ぐため、事前に十分なプリロードバッファを確保する設計を推奨。
