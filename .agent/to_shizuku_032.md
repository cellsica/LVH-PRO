## 🎯 今回の目標

1.  **LanguageManager の新設**: 言語データを管理し、ID で文字列を取得できる基盤を作る。
2.  **主要な文字列のリソース化**: ハードコードされている UI 文字列を外部ファイル（または定義）に逃がす。
3.  **切り替え機能の実装**: 設定画面で言語を変えた瞬間に、全ウィンドウの表示が切り替わるようにする。

---

## 🛠 実装詳細

### 1. LanguageManager クラスの新設
- **構造**:
    - `Language` enum（English, Japanese）を用意してね。
    - 文字列データを ID（例: `STR_LOAD`, `STR_MIXER`）と対地させたマップ等で保持。
- **利用方法**:
    - `LvhStrings::get ("STR_LOAD")` のように呼び出せると使いやすいかな。
- **保存**:
    - 現在の言語設定を `ApplicationProperties` に保存して、次回起動時に復元可能にしてね。

### 2. UI 文字列のリソース化 (第一弾)
- まずは以下の主要な箇所の文字列を ID 化して実装してね。
    - **Main Toolbar**: CPU, MIDI Monitor 等のラベル
    - **Stage Window**: LOAD, ADD, NEW, OPEN, SAVE 等のボタン・メニュー
    - **Mixer Window**: MASTER ラベル、ミュート、ソロ等のコンテキスト
    - **Settings Window**: 各タブの名前やオーディオ設定の項目名

### 3. 設定画面への組み込み ＆ 即時反映
- **Settings コンポーネントへの追加**:
    - 言語選択の ComboBox を追加してね。
- **即時反映の仕組み**:
    - 言語が切り替わったら `onLanguageChanged` 等のコールバックを発火。
    - `UIManager` 経由で、開いている全ウィンドウ（Stage, Mixer, Settings 等）に `refresh()` をかけて、表示される文字列を更新してほしいんだ。
