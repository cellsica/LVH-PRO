# LIGHT-VST-HOST Pro版 構想 (Vision)

## 概要
LIGHT-VST-HOST (LVH) コアをベースとし、実用性と付加価値を極限まで高めたプロフェッショナル仕様のバリエーション。

## 1. 音声・プラグイン管理
- **複数プラグインの同時ロード**: 
  - 直列(チェーン)や並列(レイヤー)で複数のVSTを自由に接続。
- **ミキシングコンソール機能**:
  - 各プラグインごとに独立したボリュームコントロール。
- **お気に入り機能**:
  - 頻繁に使用するプラグインをリストの上位に固定。

## 2. 視覚効果 (Visualizers)
- **高精度メーター**: 
  - VUメーター、ピークメーター、スペクトラムアナライザの搭載。
- **こだわりの演出**:
  - VUメーターの針が0VUを超えた際、バックライトが警告色（赤色等）に変化するアナログライクな視覚効果。

## 3. 高度なMIDIルーティング
- **マルチMIDIデバイス対応**:
  - 複数のMIDIコントローラーを同時に接続し、個別にプラグインへルーティング。
- **インテリジェント・フィルタリング**:
  - デバイス名やMIDIチャンネルに基づいた動的ルーティング。
- **キーボード・スプリット**:
  - 特定の音域（キーレンジ）ごとに異なるプラグインを割り当て（例：左手でベース、右手でリード）。

## 4. パーソナライズ (Skinning)
- **WinAmp風スキンシステム**:
  - ユーザーが画像やリソースを用意することで、外観をガラリと変えられる機能。

## 5. 耐障害性と信頼性
- **サンドボックス（別プロセス）実行**: 
  - 特定のプラグインがクラッシュしても、ホストや他のプラグインを巻き添えにしない（ライブ仕様）。
