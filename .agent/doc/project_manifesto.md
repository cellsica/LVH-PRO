# LIGHT-VST-HOST プロジェクト・マニフェスト (Manifesto)

## 1. 茜の現場提言 🎸
現場のプレイヤー・コンポーザーとしての視点から、以下の要素を最優先事項とする。

- **「設定は面倒でも、音が一番速く出る安定感」**:
  - ステージやレコーディングでは、微小なレイテンシーやノイズが演奏のノリを左右する。ADC（自動遅延補正）は「信頼の証」。
- **モジュラーな使い勝手**:
  - 「昨日のエフェクト設定を今日の楽器にサクッと繋ぐ」ような、プロジェクトを跨いだセッティングのポータビリティ。
- **ライブ中の絶対的な安心感**:
  - 万が一特定のプラグインが落ちても、システム全体（音）が止まらないプロセス隔離の仕組み。

## 2. なべの技術構想 💻
開発者兼ユーザーとしての、LVHの究極的な進化形。

### 構成と管理
- **複数プラグインの同時ロード**: チェーン（直列）やレイヤー（並列）での接続。
- **ミキシングコンソール**: チャンネルごとのボリュームコントロールと VU メーター（針が振り切れるとバックライトが赤くなる演出付き）。
- **お気に入り機能**: 頻繁に使うプラグインへのクイックアクセス。

### 高度なMIDIルーティング
- **マルチデバイス対応**: デバイス名やチャンネルによる「インテリジェント・フィルタリング」。
- **キーボード・スプリット**: 指定したノート番号で音源を分ける設定。

### 外観と体験
- **スキンシステム**: WinAmp風の、ユーザーリソースによる自由な外見変更。

## 3. かえでの設計指針 🛠️
上記を技術的に実現するためのエンジニアリング原則。

- **ゼロコピーの徹底**: プロセス内バッファ共有によるオーバーヘッドの最小化。
- **グラフの平坦化**: 複雑な内部接続を最終的に単一の計算グラフへ展開し、JUCEの最適化を活かす。
- **スケーラビリティ**: 「シングルコア」のLVHから「マルチインスタンス」のPro版へ、コードを壊さずに拡張できるクラス設計。
