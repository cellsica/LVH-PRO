# 【しずく（Claude Code）への依頼】第5回：UIブラッシュアップとアクセシビリティ改善

## 1. 依頼内容
プリセット機能の実装お疲れ様！なべさんからさらに使いやすくするための改善案をもらったよ。
ツールバーの整理、設定画面の準備、そしてPCキーボードでの演奏機能の追加をお願いします。

## 2. 実装のゴール

### A. ツールバーのアイコン化
- **内容**: 以下のボタンをテキストから「アイコン」に変更して、ツールバーをスッキリさせてください。
    - `PRESET`, `LOAD`, `UNLOAD`, `PANIC`, `KBD`
- **ヒント**: 適切なアイコン（ディスク、フォルダ、ごみ箱、警告マーク、鍵盤など）を `juce::Path` で描画するか、デフォルトのシンボルを活用してください。

### B. 設定画面への入り口
- **内容**: ツールバー左端の「LVH」ロゴを**右クリック**したときに、ポップアップメニューで「Settings...」を表示できるようにしてください。
- **挙動**: 現時点では「Settings...」をクリックしても `AlertWindow` で「Under Construction」と出るだけでOKです。将来の拡張用のフックを作っておくのが目的です。

### C. 仮想キーボードの初期状態変更
- **内容**: 起動時の仮想キーボードの高さを、現在のデフォルト（100px等）ではなく「最小サイズ（50px）」で表示されるように調整してください。

### D. PCキーボードでの演奏機能 (Computer Keyboard MIDI)
- **内容**: PCのキーボードを使って MIDI ノートを鳴らせるようにしてください。
- **キーアサイン**: 
    - 下段（白鍵）: `Z` (C4), `X` (D), `C` (E), `V` (F), `B` (G), `N` (A), `M` (B), `,` (C5)
    - 中段（黒鍵）: `S` (C#), `D` (D#), `G` (F#), `H` (G#), `J` (A#)
- **UI表示**: `MidiKeyboardComponent` の鍵盤上に、対応するキートップの文字（Z, X, S...）をオーバーレイ表示してください。
- **実装**: `MainComponent` でキーイベントをハンドルし、`keyboardState` にノートオン/オフを伝達するようにしてください。
