## 🎯 今回の目標

1.  **Stage セットメタデータと命名の改善**: セットリスト自体に名前をつけ、管理しやすくする。
2.  **未保存変更の確認 (Dirty Check)**: 操作ミスによるデータ紛失を防ぐ。
3.  **「選択」と「アクティブ」の分離**: ライブ中の視覚的な誤解をなくす。
4.  **操作性の洗練**: ドラッグ＆ドロップ、右クリックメニュー、ウィンドウの永続化。

---

## 🛠 実装詳細

### 1. `StageManager` の機能拡張
-   **Dirty フラグの実装**:
    -   `bool isDirty_` メンバーを追加してね。
    -   `addItem`, `removeItem`, `moveItem`, `setSetName` など、データに変更があったら `true` にする。
    -   `loadSet`, `saveSet`, `newSet` 完了時には `false` にリセットすること。
-   **setName の保存**:
    -   JSON 形式への `setName` フィールドの書き出し・読み込みが確実に行われるように確認してね。

### 2. `StageWindow` の UI ブラッシュアップ
-   **ウィンドウタイトルと名前編集**:
    -   タイトルを `Stage - [SetName]` 形式にする。
    -   ツールバー等に `setName` を編集できる `juce::Label` (editable) を追加してね。
-   **Selection vs Active (最重要)**:
    -   現在、クリックすると即座にハイライトされるけど、「クリック＝選択」「ロードボタン＝実行」と役割を分けてほしいんだ。
    -   **選択状態 (Selected)**: 項目の枠線を描画する、あるいは淡いハイライト。まだ音は切り替わらない。
    -   **アクティブ状態 (Active)**: `loadItem` が成功し、実際にプロジェクトがロードされた項目。これまでの「グリーン背景」はこの状態のために予約してね。
-   **ドラッグ＆ドロップ**:
    -   `juce::ListBoxModel` の `shouldElementBeSelected` や `getDragSourceDescription` を使って、リスト内での並び替えを視覚的に行えるようにしてね。
-   **右クリックメニュー**:
    -   項目上で右クリックした時に `Rename Alias` (名前変更) や `Delete` ができるようにしてほしいな。

### 3. メニューと安全性の統合 (`UIManager` / `LvhProApplication`)
-   **メニュー改名**: `[Pro] Stage Performance Mode` -> `Open Stage Set` に変更。
-   **終了/切替時の確認**:
    -   `newSet` や `loadSet` を呼ぶ前に `manager.isDirty()` をチェック。
    -   もし変更があれば `juce::NativeMessageBox` で「変更を保存しますか？」と確認を出してね。
-   **ウィンドウの復元**:
    -   `MixerWindow` と同様、`StageWindow` の表示状態と座標を `ApplicationProperties` に保存・復元するようにしてほしいんだ。
