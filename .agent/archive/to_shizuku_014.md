## 今回のミッション

### 1. `PluginSlot` の Pro版リファクタリング
さっき相談してくれた「PluginSlot への統合」、ぜひ進めてほしいな。
- **内容**: 
  - `PluginSlot` クラスが `std::unique_ptr<BridgeInstance>` を保持できるようにリファクタリング。
  - `Main.cpp` で直接 `OwnedArray<BridgeInstance>` を持つのではなく、スロット経由で各インスタンスを管理する構造にしよう。
  - プロセス起動やリソース破棄もスロットの責務に含めると管理が楽になるはずだよ。

### 2. MIDI 個別ルーティング（Active Slot）の実装
「どのプラグインを弾いているか分からない」問題と「全部のプラグインが鳴っちゃう」問題を同時に解決しよう。
- **内容**:
  - `Main.cpp` またはスロットマネージャーに `activeSlotIndex`（現在選択されているスロット）を導入。
  - Core 側の仮想キーボードや外部 MIDI 入力は、その時 **Active なスロットの BridgeInstance にのみ** 送信されるように修正してね。

### 3. UI でのブラッシュアップ（暫定）
- **内容**:
  - 現在開いているブリッジ（スロット）を切り替えられる UI（コンボボックスやボタンなど）を Core 側に追加。
  - これで「今どのプラグインに MIDI を送っているか」が明示的に分かるようにしよう。

### 4. その他、013で見つかった懸念事項の解消
- ウィンドウのライフサイクル管理など、もし余裕があったら少し手を付けてみてね。
