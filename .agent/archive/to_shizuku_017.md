## 今回のミッション

### 1. AudioEngine の「直列ルーティング」対応
シンセサイザーの出力を、別のエフェクト（Bridge）に順番に流し込む仕組みを、Core 側の `AudioGraph` で実現してね。

- **内容**:
  - `rebuildBridgeGraph()` を拡張して、Bridge 同士を直列に繋ぐ「エフェクトチェイン」を構築できるようにする。
  - **識別**: 各 `BridgeInstance` が「音源（Instrument）」なのか「エフェクト（Effect）」なのかを判定できるようにしてね。
  - **ルーティング**: 
    - シンセの出力を最初のエフェクトの入力へ。
    - 前のエフェクトの出力を次のエフェクトの入力へ。
    - 最後のエフェクトの出力をマスター（Gain+Meter）へ。

### 2. Bridge 側での VST3 Effect 対応
Bridge プロセスが、「楽器（Instrument）」だけでなく「エフェクト（Effect）」としても正しく動くように調整しよう。

- **調整点**:
  - Audio I/O の有効化。
  - `AudioProcessor::processBlock` で入力オーディオをプラグインに流し込む処理。
  - `InterprocessConnection` を通じて、Core から送られてくる「エフェクト用オーディオデータ」のハンドリング。

### 3. プロジェクト保存（.lvh）への反映
Mission 016 で作った XML 保存機能を拡張して、「チェインの並び順」も保存・復元できるようにしてね。

- **XML 構造**:
  - `<Bridges>` セクション内で、どのシンセにどのエフェクトが紐づいているかが分かるように。

### 4. （おまけ）UI の準備
次のミッション（Mission 018）で「ミキサー画面」を作る準備として、ロゴ右クリックメニューから「エフェクトとして Bridge を起動」できるように項目を追加しておいてくれると助かるな。
