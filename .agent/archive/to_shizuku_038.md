## 🎯 今回の目標 (Mission 035-D)

独立したメトロノーム管理機構と、操作しやすい独立 UI ウィンドウを実装してほしいんだ。

### 1. `MetronomeManager` クラスの新設
*   **BPM管理**: 40〜240 BPM（デフォルト 120）。
*   **拍子設定**: まずは 4/4 拍子からでOKだけど、拍子変更（3/4, 6/8 他）も考慮しておいて。
*   **オーディオ生成**: 
    *   1拍目は高音（Hi）、それ以外は低音（Lo）のクリック音を生成。
    *   `MetronomeManager` は内部で `juce::AudioSource` や `juce::AudioProcessor` 相当のプロセスブロックを持って、メインのオーディオグラフにクリック音を流せるようにして。
*   **Tap Tempo**: ボタン連打で BPM を推定するロジック。
*   **状態通知**: 現在の拍（1, 2, 3, 4）を UI に通知するコールバック。

### 2. UI：`MetronomeWindow` の構築
*   **独立ウィンドウ**: ミキサーと同じく `MixerWindow` の構成を参考にして、独立したフローティング・ウィンドウとして作ってね。
*   **機能**: 
    *   Start/Stop ボタン。
    *   BPM 入力（数値入力 ＋ スライダー）。
    *   「Tap Tempo」ボタン。
    *   出力音量の調整スライダー。
    *   **Pins (Always on Top)**: アイコンを使って、最前面に固定できる機能（`Icons::pin` を活用）。
*   **ビジュアル**: ステージでの視認性を高めるため、拍の進行に合わせて光る「LED」のような視覚ガイドもほしいな！

### 3. MIDI・トランスポート連動
*   **MIDIリモート**: 特定の MIDI CC や Program Change で再生・停止ができるように、`UIManager` 経由でフックできるようにしておいて。
*   **AudioPlayHead 連携**: メトロノームの BPM 情報を各 Bridge (VST3) に流すための `juce::AudioPlayHead` 派生クラスの作成を見据えて、BPM 情報を `AudioEngine` に渡す仕組みを考えてみて。
