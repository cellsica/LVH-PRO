## 🛠 実装詳細

### 1. Core ツールバーへのボタン追加
- **`UiCommon.h`**: `Icons::stage` 関数を新設してね。リストやセットリストを連想させるアイコン（3本線に枠など）だと嬉しいな。
- **`MainComponent`**:
    - `stageToggleButton` (`IconButton`) を追加。
    - プロパティや `resized()` で、ミキサーボタンの隣あたりに配置してね。
- **`UIManager`**:
    - `mc_->onStageToggle` を受け取って、`toggleStageWindow` を呼び出すように接続してね。
    - `restoreStageWindow` 時にもボタンのトグル状態が同期するように調整をお願い。

### 2. 日本語文字化けの修正 (最優先!)
- 現在、エイリアス等に日本語を入れると文字化けしてしまうみたい。
- **原因の切り分け**: ソースコード内のリテラル、JSON 保存時の Unicode 変換、あるいはフォントの欠如を確認してほしいんだ。
- **対策案**:
    - UI 全体、または `StageWindow` のフォントを日本語対応のもの（`juce::Font::getDefaultSansSerifFontName()` 等）に明示的に設定する。
    - `StageManager` の JSON 保存/読込時に `juce::CharPointer_UTF8` を確実に通るようにする。

### 3. キーボードショートカットの実装
- `StageWindow` がフォーカスされている時、以下の操作を可能にしてね。
    - **`Up / Down` キー**: リストの「選択（青枠）」を上下に移動。
    - **`Enter` キー**: 現在選択されている項目を `LOAD`（実行）。
- `StageWindow` (DocumentWindow) の `keyPressed` をオーバーライドして実装するのがスムーズかな。

### 4. ロードエラーの通知 (防御的プログラミング)
- `.stg` ファイルに記録されている `.lvh` ファイルが、削除や移動で存在しない場合があるよ。
- **実装内容**:
    - `StageManager::loadItem` 内で `File::existsAsFile()` をチェック。
    - もし存在しなければ `juce::NativeMessageBox` で「プロジェクトファイルが見つかりません」と警告を出して、ロードを中止してね。

### 5. 保存状態の明示 (Dirty Indicator)
- `StageWindow` のタイトルバーを、保存されているかどうかが一目でわかるようにしたいんだ。
- **実装内容**:
    - `StageWindow::refresh()` 内で、`manager.isDirty() == true` の場合にタイトル末尾に `*` を追加してね。
    - 例: `Stage - Set2024 *`
