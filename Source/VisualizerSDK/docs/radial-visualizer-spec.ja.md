# RadialVisualizer プラグイン仕様書

**対象プラグイン:** RadialVisualizer  
**バージョン:** 1.0  
**対象読者:** サードパーティ開発者（バイブコーダー含む）

---

## 1. 概要

RadialVisualizer は、音楽の周波数エネルギーを円形に可視化するビジュアライザープラグインです。

中心から広がる「波紋リング」と、円周上に並ぶ「放射バー」の2つの主要要素が連動し、オーディオ信号に対して生き生きとしたリアクションを表示します。静かなパッセージでは繊細なパルスが、ダイナミックなサウンドでは力強いリングの拡散が生まれます。カラーリングはドップラー効果を模したグラデーション（中心＝赤 → 外縁＝バイオレット）で、音の「距離感」を視覚的に表現します。

**推奨キャンバスサイズ:** 520 × 520 px

---

## 2. 描画レイヤー構成

描画は以下の4つのレイヤーを順番に重ねて行います。

| レイヤー順 | レイヤー名 | 内容 |
|:---:|:---|:---|
| 1 | バックグラウンド | 単色の黒背景 |
| 2 | 波紋リング（Wave Rings） | 中心から外側へ広がる同心円リング群 |
| 3 | 放射バー（Radial Bars） | 中心を起点とする周波数バー（512本） |
| 4 | ニュークリアス（Nucleus） | 中心のグロー円と5個の軌道パーティクル |

各レイヤーは独立して描画され、上位レイヤーが下位レイヤーに重なります。

## 3. FFT データ処理

### 3.1 入力

- FFT サイズ: **512 ビン**（`kRawBins = 512`）
- 使用周波数レンジ: bin 1 〜 bin 480（DC 成分・ナイキスト近傍を除外）

### 3.2 16バンドへの集約

512 ビンを **16 のログスケールバンド**に集約します。

```
bandBounds: log2(1) 〜 log2(480) を 16 等分
```

各バンドに対応するビン範囲の振幅平均を計算し、`band[0..15]` として格納します。

```
band[b] = average( fftMagnitude[binStart..binEnd] )
```

ログスケールにより、低周波数域（bass）は細かく、高周波数域（treble）は広く集約されます。これにより人間の聴覚特性に近い周波数感度を実現します。

### 3.3 全体エネルギーの計算

リング放出判定に使用する平均エネルギー：

```
avgEnergy = average( band[0..15] )
```

## 4. 波紋リング仕様

### 4.1 WaveRing 構造体

```cpp
struct WaveRing {
    std::array<float, kBands> band {};  // 16バンドのスナップショット
    float baseRadius  = 0.f;            // 生成時の基準半径
    float emitEnergy  = 0.f;            // 生成時のエネルギー（0〜1）
};
```

### 4.2 リング放出ロジック

1. **フレーム間隔チェック:** `kEmitInterval`（3フレーム）ごとに放出を試みます。
2. **エネルギー閾値チェック:** `avgEnergy > kEmitThreshold`（0.00008）の場合のみ放出します。
3. **エネルギー正規化:**
   ```
   ring.emitEnergy = min( sqrt(avgEnergy / 0.05), 1.0 )
   ```
4. **バンドスナップショット:** 放出時の `band[0..15]` をリングに記録します。
5. **リング数制限:** 最大 `kMaxRings`（45個）。超過した場合は最古のリングを削除します（FIFO）。

### 4.3 リングの拡張

毎フレーム、各リングの現在半径は以下で計算されます：

```
currentRadius = baseRadius + framesAlive * kEmitSpeed
```

リングが画面外（半径がキャンバス対角線を超える）になると自動消滅します。

### 4.4 ストローク幅（アタック〜ディケイ感）

放出直後は太く、拡張につれて細くなることで「アタック → ディケイ」の感触を演出します。

```
strokeThick = 1.8 + ring.emitEnergy * 2.2   // 生成直後（progress=0）
strokeThin  = 0.5 + ring.emitEnergy * 0.5   // 拡張後（progress=1）
strokeW     = strokeThin + (1 - progress) * (strokeThick - strokeThin)
```

`progress` = `currentRadius / maxRadius`（0〜1）

### 4.5 定数一覧

| 定数名 | 値 | 説明 | 変更効果 |
|:---|:---:|:---|:---|
| `kEmitSpeed` | 2.0 | 毎フレームのリング拡張速度（px） | 大きくすると波紋が素早く消える。小さくすると長く残る |
| `kEmitInterval` | 3 | リング放出のフレーム間隔 | 小さくすると波紋が高頻度で発生。大きくするとスパース |
| `kMaxRings` | 45 | 同時表示リングの最大数 | 増やすと残像が多くなる。減らすと少なくなる |
| `kEmitThreshold` | 0.00008 | リング放出の最低エネルギー閾値 | 大きくすると静音時にリングが出なくなる |

## 5. 放射バー描画

### 5.1 バーの本数と角度

512 本の放射バーを均等に円周上へ配置します。

```
angle[i] = i * 2π / 512    (i = 0..511)
```

### 5.2 コサイン補間による滑らかなバンド値

512 本のバーに対し、16 バンドの値を **コサイン補間**で滑らかに補間します。

```
float bandAtAngle(band[], t):
    pos  = t * kBands                     // 連続位置（0〜16）
    lo   = floor(pos) % kBands            // 下バンドインデックス
    hi   = (lo + 1) % kBands             // 上バンドインデックス
    frac = pos - floor(pos)              // 小数部分
    mu   = (1 - cos(frac * π)) * 0.5    // コサイン補間係数
    return band[lo] * (1 - mu) + band[hi] * mu
```

`t` = `i / 512`（バーの正規化インデックス）。コサイン補間により線形補間よりも滑らかな形状になります。

### 5.3 バーの描画

各バーはキャンバス中心から外側へ向けて描画します。

```
startX = cx + cos(angle[i]) * innerRadius
startY = cy + sin(angle[i]) * innerRadius
endX   = cx + cos(angle[i]) * (innerRadius + barHeight)
endY   = cy + sin(angle[i]) * (innerRadius + barHeight)
```

`barHeight` は `bandAtAngle` の返値に応じてスケールされます。

### 5.4 カラーリング（ドップラーカラー）

各バーの色は、最も近い波紋リングの `progress` 値に基づき決まります。

```
hue = 0.0 + progress * 0.72   // 0.0（赤）〜 0.72（バイオレット）
```

波紋リングが存在しない場合はデフォルト色（白や暗めの青系）を使用します。

## 6. ニュークリアス

### 6.1 コア円（グロー）

キャンバス中心に発光感のある円を描画します。

- 外側から内側に向けて透明→不透明に変化するラジアルグラデーションを使用。
- 音量エネルギーに応じてグロー半径が微妙に変動します。

### 6.2 軌道パーティクル

5個のパーティクルがコア周囲を公転します。

```cpp
struct Particle {
    float orbitRadius;  // 公転半径（px）
    float speed;        // 公転角速度（rad/frame）
    float phase;        // 初期位相（rad）
    float dotSize;      // ドットの直径（px）
};
```

各パーティクルは異なる `orbitRadius`・`speed`・`phase` を持ち、規則性のない有機的な動きを演出します。毎フレームの位置計算：

```
x = cx + cos(phase + speed * frame) * orbitRadius
y = cy + sin(phase + speed * frame) * orbitRadius
```

## 7. チューニングガイド

以下の定数を変更することでビジュアルの性質を大きく変えられます。

| 定数名 | 値 | 説明 | 変更効果 |
|:---|:---:|:---|:---|
| `kRawBins` | 512 | FFT ビン数 | 変更時はバンド集約ロジックの見直しが必要 |
| `kBands` | 16 | 周波数バンド数 | 増やすと細かい周波数分解能。バー描画の補間ロジックも要調整 |
| `kEmitSpeed` | 2.0 | リング拡張速度（px/frame） | 大きくすると波紋が速く消える。小さくすると長く残る |
| `kEmitInterval` | 3 | リング放出間隔（フレーム） | 小さくすると波紋が密になる。大きくするとスパース |
| `kMaxRings` | 45 | 同時最大リング数 | 増やすと画面が賑やかになる。減らすとシンプルになる |
| `kEmitThreshold` | 0.00008 | 放出エネルギー閾値 | 大きくすると閾値が上がり、静音時に波紋が出なくなる |

### ストローク幅パラメーター

| パラメーター | デフォルト計算式 | 変更効果 |
|:---|:---|:---|
| `strokeThick` | `1.8 + emitEnergy * 2.2` | 新リングの太さ。係数を増やすと太くなる |
| `strokeThin` | `0.5 + emitEnergy * 0.5` | 拡張後の細さ。係数を増やすと細い部分でも太くなる |

### カラーパラメーター

| パラメーター | デフォルト値 | 変更効果 |
|:---|:---:|:---|
| hue（中心） | 0.0（赤） | 変更するとカラーレンジの開始色が変わる |
| hue（外縁） | 0.72（バイオレット） | 変更するとカラーレンジの終端色が変わる |

## 8. バイブコーディング向けプロンプト例

以下のプロンプトを AI アシスタントに貼り付けることで、プラグインの改造アイデアを素早く得られます。

---

**プロンプト例 1: カラースキームの変更**

```
LVH の RadialVisualizer プラグインを改造したい。
現在、波紋リングのカラーは progress 0（中心）で hue=0.0（赤）、
progress 1（外縁）で hue=0.72（バイオレット）になっている。
これをシアン（hue=0.5）からライムグリーン（hue=0.25）へ変化するように書き換えてほしい。
変更箇所は RadialVisualizer.cpp のドップラーカラー計算部分のみでよい。
```

---

**プロンプト例 2: リングの残像を増やす**

```
LVH の RadialVisualizer プラグインで、
現在 kMaxRings=45、kEmitInterval=3 になっている。
波紋リングをより多く・より長く画面に残すように定数を調整したい。
具体的に kMaxRings と kEmitSpeed の値を変更する提案と、
その場合のパフォーマンスへの影響を教えてほしい。
```
